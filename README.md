# afiqsazlan/tap

Homebrew casks for apps by Afiq Sazlan.

```bash
brew install --cask afiqsazlan/tap/lapang
```

| Cask | App |
|---|---|
| `lapang` | [Lapang](https://github.com/afiqsazlan/lapang), a menu bar app that keeps an eye on what fills a developer's Mac |

Casks here are updated by each app's release script. Lapang updates itself through Sparkle (`auto_updates true`), so `brew upgrade` skips it unless you pass `--greedy`.
